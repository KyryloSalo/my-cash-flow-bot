# Легкий рух

Готові GIF: `assets/bob/*.gif` і `assets/capi/*.gif`. Кожен — 256 × 256 px, 45 кадрів, приблизно 3 секунди, нескінченний цикл. PNG — 512 × 512 px, непрозорий світлий фон. Ілюстрація рухається як ціле; це не риг персонажа. Оглядові GIF у `previews/` показують шість різних ефектів для кожного талісмана.

Для застосунку підключити `achievements.css` і кольоровий PNG. `motion` у JSON визначає `data-effect`. При отриманні можна обмежити кількість повторів до одного; каталог показує лише делікатний рух у видимій області. Ефекти не впливають на прогрес.

```html
<div class="award-visual" data-effect="celebrate">
  <img src="assets/bob/29-goal-completed.png" alt="Мрія здійснилася" width="512" height="512">
  <i class="spark" aria-hidden="true"></i>
  <i class="spark" aria-hidden="true"></i>
  <i class="spark" aria-hidden="true"></i>
  <i class="shine" aria-hidden="true"></i>
</div>
```

| Значення | Характер руху |
|---|---|
| `glow` | Світіння, легке підняття, дрібні іскри |
| `voice` | М’яке погойдування; у GIF додатково пульсує індикатор голосу |
| `scan` | Прозора смуга сканування |
| `shine` | Повільний світловий відблиск |
| `shield` | М’яке прохолодне світіння навколо захисту |
| `celebrate` | Теплий золотий акцент та іскри |
| `family` | Дуже легке погойдування спільної ілюстрації |
| `goal` | Невеликий пульс масштабу |

GIF є оглядовим виконанням тих самих ефектів, а не покадровою копією CSS-рендера.

Закритий стан: додати `.is-locked`, замінити `src` на відповідний `-locked.png`. Він статичний. Клас `.motion-off` на контейнері прибирає рух; системний `prefers-reduced-motion` завжди має пріоритет. `.is-paused` на невидимій картці або `.page-hidden` на body призупиняє рух без перемотування.

Не анімувати 72 GIF одночасно й не передавати їх усі у початковому завантаженні. На слабких пристроях використовувати статичні PNG. Для нагороди screen reader отримує текст «Отримано: [назва]», декоративні ефекти — `aria-hidden`.
