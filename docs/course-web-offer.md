## Посилання для уроку

`https://vydno.capital/?start=course`

Артефакт уже розгорнуто; перед масовою публікацією в курсі завершити реальний Telegram-вхід, підтверджену прив'язку картки та перевірку бонусу й установленої PWA. Публічні browser-перевірки пройшли, але не замінюють ці дії власника облікового запису/картки/пристрою. Звичайне посилання без параметра зберігає стандартну пропозицію. Старе Telegram-посилання `https://t.me/vydnocapital_bot?start=course` залишається чинним.

## Маршрут і обмеження

1. На канонічному `/`, сторінці `/pwa-v2/` і в quiz всі реєстраційні CTA передають `start=course` на наявний Telegram OIDC web-login. Пропозиція зберігається в localStorage для повернення без параметра; переходи між лендингом і quiz також передають параметр у URL, у тому числі коли localStorage недоступний.
2. Сервер приймає лише значення `course`, прив'язує його до одноразового OIDC flow та переносить у `UserAdminState.pending_start_payload` після перевіреної ідентифікації. Відновлення callback без початкової cookie використовує збережений серверний flow. Наявна непорожня кампанія не перезаписується.
3. Звичайний онбординг, вибір категорій і створення фінансового простору не скорочуються. На екрані прив'язки картки відображаються 90 днів та чинні умови перевірки картки й наступного автопродовження. Потрібна явна згода з умовами перед відкриттям Monobank.
4. Тривалість, ціна та курсова пропозиція визначаються сервером. BillingConsent зберігає `offer_id=askills_course_90d`; наявний billing-механізм активує 90 днів лише після підтвердженого save-card платежу. URL повернення з checkout не є доказом оплати. Повторний callback не подовжує підписку.
5. Після активованого 90-денного trial зі збереженою карткою API повертає `access.course_bonus`. Потрібна відповідність: користувач, поточна trial-підписка, оплачений BIND, курсова згода та визначене перше продовження. Звичайний trial, інша 90-денна акція, невдала/незавершена прив'язка та вже поновлена підписка не дають цього підтвердження.
6. Послідовність: онбординг → підтверджена прив'язка картки → бонус курсу → чинна пропозиція встановлення PWA / можливість пропустити. Вікна не перекриваються. Якщо PWA вже встановлено або підказка не належить до показу за чинними правилами, зайве встановлення не пропонується.
7. Бонусне вікно закривається кнопкою «Дякую» або Escape, підтримує focus trap та повернення фокусу. Закриття зберігається на пристрої окремо для користувача й ID згоди; повторний вхід не створює новий trial. На іншому пристрої підтвердження може бути показане знову.

> Дякуємо, що обрали нас! Даруємо вам 90 днів безкоштовного користування, оскільки ви є студентом курсу «Фінансова грамотність» на платформі askills.pro.
